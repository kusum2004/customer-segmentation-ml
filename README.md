Customer Segmentation Analysis using Machine Learning
📌 Project Overview

This project focuses on performing Customer Segmentation using Machine Learning techniques to analyze customer behavior and group customers based on similar characteristics. The project helps in identifying different customer segments for better business decision-making and targeted marketing strategies.

The analysis was performed using Python, Pandas, NumPy, Matplotlib, Seaborn, and Scikit-learn libraries.

📊 Dataset Information

The dataset contains customer-related information such as:

Customer Age
Gender
Income Level
Coverage Amount
Premium Amount

The dataset was preprocessed and analyzed to identify meaningful customer groups using clustering techniques.

🔍 Project Workflow
1. Data Preprocessing
Handled missing values
Converted categorical data into numerical format
Selected important features for clustering
Applied feature scaling using StandardScaler
2. Exploratory Data Analysis (EDA)
Analyzed customer demographics
Visualized customer distributions
Compared customer income and premium patterns
3. Customer Segmentation
Applied K-Means Clustering algorithm
Grouped customers into different clusters
Visualized customer segments using scatter plots
4. Cluster Analysis
Calculated average values for each cluster
Compared customer groups using bar charts
Identified high-value and low-value customer segments
